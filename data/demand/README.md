# Simulated demand

`werkdag.csv` is one fictitious working day of AI demand for the four fictitious organisations, generated by [`tooling/inferentienet/demand.py`](../../tooling/inferentienet/demand.py) with a fixed seed. Regenerate it with `python -m inferentienet.demand` in `tooling/`; CI checks that it is reproducible.

| Column | Meaning |
|---|---|
| `slot`, `time` | 15-minute slot (0 to 95) and its start time |
| `workload_id` | Unique id: organisation, time, and data class and task or a job name |
| `org` | Fictitious organisation from `network.yaml` |
| `tier` | `kritiek`, `interactief` or `batch` |
| `data_class` | `openbaar`, `intern`, `vertrouwelijk` or `bijzonder` |
| `task` | `chat`, `samenvatten`, `classificeren`, `zoeken`, `vertalen` or `analyse` |
| `requests` | Number of requests in this workload |
| `tokens_in`, `tokens_out` | Total input and output tokens |
| `ref_gpu_seconds` | Work in reference GPU-seconds with the default model of the task's model class (for information; the router recomputes it per site) |
| `description` | Name of a batch or critical job; empty for interactive bundles |

How it is made: interactive demand follows an office-hours profile per organisation, scaled to a share of that organisation's own capacity, with a little seeded noise; batch and critical jobs are a fixed list in `demand.py`. The municipalities deliberately ask for more than their own capacity, and for a model size they do not have.
