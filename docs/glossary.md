# Glossary

| Term | Meaning in this challenge |
|---|---|
| **Inferentie (inference)** | Running a trained AI model to answer a request, as opposed to training it. |
| **AI-gateway** | A service between applications and models that receives AI requests and decides where they run. |
| **Federatief gateway-model** | Every organisation runs its own gateway, for internal routing and for external routing to the other members. Approach A in the brief. |
| **Federatie** | In the starter: the four government organisations that share capacity with each other. |
| **Eigen kolom** | An organisation's own chain of systems and responsibility. "Data never leaves its own column" means: not even to another government organisation. |
| **Datagevoeligheid / data class** | How sensitive the data in a request is. The starter uses four simplified classes: `openbaar`, `intern`, `vertrouwelijk`, `bijzonder`. |
| **Tier** | Priority class of a request: `kritiek`, `interactief`, `batch`. Also used for pricing. |
| **Slot** | A block of 15 minutes. Capacity is planned and settled per slot. |
| **Receiving protection (ontvangersbescherming)** | A site only takes work from others up to a limit, to protect its own users. |
| **Minimum gain (minimale winst)** | A request only moves when that saves enough time or money. |
| **Switching toll (overstaptol)** | A penalty on moving work in the routing decision, to stop needless moves. |
| **Solidarity reserve** | In the starter: a share of every site that other members may use for critical work. |
| **Braess's paradox** | The effect, known from road traffic, that more route options can make everyone slower when everyone picks their own fastest route. |
| **Chargeback / verrekening** | Charging usage to the organisation that caused it. "Settlement against capacity supplied" means netting what you used against what you supplied. |
| **GOPACS** | The platform through which Dutch grid operators solve grid congestion with flexibility from market parties. Inspiration for approach B. |
| **Capaciteitsbeperkingscontract** | Capacity limitation contract: a party agrees in advance to use less capacity at peak times, for a fee. |
| **ZDR** | Zero data retention: a provider does not store the content of requests. |
| **Minbzk** | Ministerie van Binnenlandse Zaken en Koninkrijksrelaties. |
| **PZH** | Provincie Zuid-Holland. |
| **VNG** | Vereniging van Nederlandse Gemeenten. |
| **GDI** | Generieke Digitale Infrastructuur: the shared digital infrastructure of Dutch government, with its own governance. |
| **AVG** | Algemene verordening gegevensbescherming, the Dutch name of the GDPR. |
| **AWR, art. 67** | Algemene wet inzake rijksbelastingen; article 67 is about fiscal secrecy. |
| **Wgr** | Wet gemeenschappelijke regelingen: the law for joint arrangements between public bodies. |
| **Wgs** | Wet gegevensverwerking door samenwerkingsverbanden. |
| **BIO2** | The current version of the Baseline Informatiebeveiliging Overheid, the information security baseline for Dutch government. |
| **EIF** | European Interoperability Framework, with legal, organisational, semantic and technical layers. |
| **sAIdkick** | The programme from which this question was put forward (see the brief). |
