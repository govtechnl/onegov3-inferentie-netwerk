# Submissions

Each team puts its work in its own folder in its fork, and opens **one Pull Request** into `main`.

```
submissions/
  <team-name>/
    README.md          what you built, how to run it, what is simulated, which LLM (if any) and where
    rules/             your routing, priority and settlement rules (data files), or your changed policy.yaml
    src/               your prototype (any language)
    tests/             tests for your rules
    governance.md      legal or administrative vehicle, governance sketch, questions for the lawyers
    LICENSE            only if you use a licence other than the repo defaults
```

The structure is a suggestion; the PR template checklist is what counts.
